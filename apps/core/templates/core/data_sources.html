Como recarregar

Recria a base a partir do xlsx e materializa as métricas diárias. Use --manter-simulacoes para preservar incidentes injetados manualmente.

python manage.py treinar_modelos

Depois de recarregar, retreine: os modelos ficam calibrados para o período em que foram treinados, e dado novo com modelo velho continua produzindo previsão — só que para uma operação que não é mais aquela.
